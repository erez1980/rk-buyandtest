# DriveCheck

יודעים מה קונים — לפני ואחרי המכון.

אתר בעברית (RTL) לקוני רכב יד שנייה: נתוני רכב והתאמת רישיון בחינם, בדיקה עצמית
לפני מכון הבדיקה, ופענוח דוח הבוחן אחריו.

## המסלול

| שלב | מה | מחיר |
|---|---|---|
| 00 | נתוני הרכב והתאמת הרישיון | חינם |
| 01 | בדיקה עצמית לפני המכון | 49 ₪ |
| 02 | פענוח הדוח אחרי המכון — נפתח רק לאחר שלב 1 | 39 ₪ |
| — | שני השלבים מראש | 79 ₪ |

השלבים נפתחים לפי הסדר; אי אפשר לדלג. הלוגיקה יושבת ב־`buytestPlans`
וב־`updateBuyTestRoadmap`, והגישה נאכפת דרך מחלקות `plan-*` ו־`stage-*` על ה־body.

## שפת העיצוב

לוח מחוונים של רכב: גרפיט כהה עם אקצנט ענבר יחיד — הצבע של נורית אזהרה בלוח
המחוונים. ירוק ואדום שמורים אך ורק למשמעות סמנטית (תקין / חריג), לעולם לא לקישוט.

```
רקע          #0c0f14      טקסט ראשי    #e9eef5
פאנל         #141922      טקסט משני    #a3b1c2
קו הפרדה     #242e3c      טקסט שלישוני #8797ab
ענבר         #ffb020 → #ff9500
תקין         #3ddc97      חריג         #ff6259
```

טיפוגרפיה: **Heebo** לממשק ולעברית, **Oxanium** למספרים ולטקסט טכני
(`font-variant-numeric: tabular-nums` כדי שספרות לא "יקפצו" בזמן עדכון).

כל הטוקנים מוגדרים ב־`<style id="drivecheck-theme">` — זו השכבה האחרונה בקובץ
והיא גוברת על שכבות העיצוב ההיסטוריות שמתחתיה.

## שכבת התנועה

מרוכזת ב־`<script id="drivecheck-motion">`, מנותקת לחלוטין מהלוגיקה העסקית.
כל אפקט עטוף ב־`safe()` — כשל באפקט לעולם לא מפיל את האתר, ותוכן לעולם לא נשאר
בלתי־נראה בגלל אנימציה (יש `revealAll()` כרשת ביטחון).

| אפקט | היכן |
|---|---|
| רצף התנעה — נוריות נדלקות יחד ונכבות אחת־אחת | טעינה ראשונה בכל סשן |
| מחוג טכומטר | בלוק האמינות ב־hero |
| גלגלת אודומטר | מחירים, ק״מ, נתוני רכב |
| נורת אזהרה נושמת | ממצאים חריגים |
| קו סריקה | כרטיסי ממצא בכניסה למסך |
| "מושך נתונים זמינים…" | שליפת נתוני הרכב |
| פס מחוונים דביק | גלובלי, מגלילה של 320px |
| מעבר שלב כמו העברת הילוך | בין שלבי המסלול |
| רשת רקע בפרלקסה | גלובלי |

`prefers-reduced-motion: reduce` מכובד — כל האנימציות נעצרות ורצף ההתנעה מדולג.

## לפני עלייה לאוויר

1. **דומיין** — כל ה־URL־ים הציבוריים מרוכזים בבלוק מסומן אחד ב־`<head>`.
   במעבר לדומיין ייעודי: להחליף שם את הבסיס ולהוסיף קובץ `CNAME` בשורש.
2. **תיבת דואר** — כתובת הקשר `support@drivecheck.co.il` מופיעה במדיניות הפרטיות
   ובמדיניות הביטול. יש להפנות אותה לתיבה פעילה לפני שמפרסמים.
3. **RLS ב־Supabase** — מפתח ה־anon חשוף בקוד המקור (כך זה אמור להיות), ולכן
   ההגנה היחידה על הנתונים היא Row Level Security. לוודא שהוא מופעל.

## הערות

- זרימות בדיקת הרכב, ה־OCR, התשלום וה־API לא שונו. נקודות הקצה של Supabase זהות.
- מזהי ה־JS ההיסטוריים (`BUYTEST_*`, `callBuyTestAnalyzeService`, מפתחות
  `localStorage`) נשארו כפי שהם בכוונה — שינוי שלהם היה מנתק משתמשים קיימים
  מהתקדמות ומרכישות שכבר שילמו עליהן.
