# RK BuyTest

גרסה ממותגת של BuyTest: מידע מקדים לרכב, בדיקה עצמית לפני המכון ופענוח דוח בדיקה לאחריו.

## עקרונות השינוי
- המיתוג והנכסים החזותיים הוחלפו לשפת מותג RK: כחול-טורקיז, סימון אימות ולוגו מקורי חדש.
- זרימות בדיקת הרכב, OCR, תשלום וה־API נשמרו כפי שהיו במקור.
- נקודות הקצה של Supabase לא שונו.

## פיתוח מקומי
`python3 -m http.server 8080` ואז לפתוח `http://localhost:8080`.
